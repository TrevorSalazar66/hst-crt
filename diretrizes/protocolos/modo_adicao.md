# Protocolo: Modo Adição (`adicao`)

Utilizado para expandir o universo sem alterar o capítulo atual.

## Fluxo de Trabalho:
1. O usuário fornece novas informações de worldbuilding, um novo NPC, uma nova facção ou um fato passado.
2. O agente insere as informações nos arquivos correspondentes em `background/fixo/`.
3. Se a adição criar novos ganchos de enredo, o agente atualiza `background/dinamico/estado_trama.json`.
4. O agente confirma a adição ao usuário.
